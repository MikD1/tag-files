# Rewrite acceptance evidence

Updated 2026-11-15. This is the implementation evidence index for the immutable
[F register](01-current-behavior.md), [D decisions](06-product-questions.md) and
[delivery gates](07-delivery-and-acceptance.md). It does not change those contracts.
Work is local on `main`; no real library, registry publication or GitHub runner
was used. Linux arm64, emulated amd64 and WebKit evidence have distinct scopes.

“Local” below means implemented and exercised by the linked source/tests on this
Linux host. It does not mean production acceptance on the owner's Mac. All rows
also depend on the unresolved cross-cutting gates at the end of this document.

## Open cross-cutting gates

- **Storage contract discrepancy:** pinned SeaweedFS 4.53 omits ListParts SHA256.
  Runtime currently reconciles immutable prior bindings and verifies every source
  byte after Complete, but the explicit checksum gate in 07 requires a provable
  ListParts checksum. This must be resolved and independently verified; successful
  SDK acknowledgements and full-file verification do not silently waive that gate.
- Native amd64 CI and actual release-triggered build/pull verification have not
  run here. Workflows are locally linted; no image was published. QEMU is separate
  evidence, with exact digests in the amd64 report.
- Actual Apple Silicon Mac/Docker Desktop: Chrome, Safari, VoiceOver, sleep,
  restart and physical power/VM interruption. Linux process restart is insufficient.
- Read-only scan and full rehearsal on a copy of the actual legacy MinIO/SQLite
  library, approximately 100 GB, including independent backup/restore, unknown
  provenance exceptions, capacity and measured operational RTO/cutover window.
- Maximum-size browser worker/upload memory and responsiveness, valid 20 GiB
  media processing, warm browser first-useful timing and the full reference
  performance profile. API RSS/streaming and small real-browser uploads cover
  different measurements.
- Final whole-change review, artifact/dependency distribution review and any
  newly discovered issues must close before production acceptance. Existing
  C#/Angular sources and explicit legacy Compose copies remain available.
